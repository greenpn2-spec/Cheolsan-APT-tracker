# 철산 갈아타기 트래커 (Cheolsan-APT-tracker)

철산주공 12/13단지로의 갈아타기(상급지 이동)를 위한 자금 갭(Gap)과 시세를
매달 기록·추적하는 개인용 Streamlit 대시보드입니다.

## 주요 기능

- 매수 목표 단지(철산주공 13단지 28평 / 12단지 27평) 호가와 보유 자산(구로 두산,
  부천 보람마을 아주) 매도 예상가를 매달 수동 입력
- 국토교통부 실거래가 공개시스템 Open API(data.go.kr)로 4개 단지의 실거래가를
  자동 수집하여 참고용으로 표시
- 부동산 순자산, 가용 현금, 대출 한도(15억 규제 반영), 최종 부족 자금(갭),
  달성률(%)을 실시간 계산
- 구로 두산(3층, 실보유 저층) 전용 저층 보정(-10%) 로직 반영 — 중고층 실거래가를
  그대로 입력하면 실제 저층 매물보다 고평가되는 오류를 방지
- 월별 기록 이력 테이블과 갭/달성률 추이 꺾은선 그래프

## 설치

```bash
pip install -r requirements.txt
```

## 실행

```bash
streamlit run app.py
```

## 국토부 Open API 키 설정

1. [공공데이터포털](https://www.data.go.kr)에서 "아파트매매 실거래 상세자료"
   API를 활용신청하고 서비스키를 발급받습니다.
2. 아래 중 한 가지 방법으로 키를 등록합니다.
   - `.env` 파일 생성 후 `MOLIT_API_KEY=발급받은키` 입력 (`.env.example` 참고)
   - 앱 실행 후 좌측 사이드바 "국토부 Open API" 섹션에서 직접 입력 후 저장
     (SQLite `settings` 테이블에 저장됨)

## 실거래가 자동 갱신

기본 갱신 주기는 **매월 1일 오전 1시(KST)** 입니다. 갱신 시각은 각 단지 카드에
"마지막 갱신: YYYY-MM-DD HH:MM (KST)" 형태로 작게 표시됩니다.

- **수동 갱신 (언제든 가능)**: 사이드바 "🔄 지금 실거래가 갱신" 버튼 — 자동 갱신
  설정과 무관하게 원할 때 바로 최신 실거래가를 가져옵니다.
- **앱 내장 스케줄러**: 사이드바 "🛰️ 자동 갱신 (매월 1일 오전 1시)"에서 시작
  버튼을 누르면 이 Streamlit 프로세스가 켜져 있는 동안 매월 1일 01:00(KST)에
  자동 실행됩니다. 단, 앱을 재시작하면 버튼을 다시 눌러야 합니다.
- **cron (권장, 앱을 계속 켜두지 않아도 동작)**: 앱과 무관하게 항상 안정적으로
  매월 1일 새벽 1시에 갱신되도록 하려면 서버의 crontab에 아래 줄을 등록하세요.

  ```cron
  0 1 1 * * cd /path/to/Cheolsan-APT-tracker && /path/to/python scheduler.py >> scheduler.log 2>&1
  ```

  (`crontab -e`로 편집기를 열고 위 줄을 추가하면 됩니다. 서버 시간대가 KST가
  아니라면 시간대에 맞게 `1 1`을 조정하세요.)

## 단지 코드(LAWD_CD) 설정

`config.py`에 기본 법정동코드(LAWD_CD)와 아파트명 매칭 키워드가 설정되어
있습니다. 실거래가 조회 결과가 비어있거나 다른 단지가 섞여 나온다면, 사이드바
"🧭 단지 코드 설정"에서 LAWD_CD와 매칭 키워드를 직접 수정할 수 있습니다.
(수정값은 코드 변경 없이 DB에 저장되어 우선 적용됩니다.)

## 핵심 연산 로직

- **부동산 순자산** = (구로두산 매도가[저층 보정, 두산에만 적용] + 부천보람 매도가) - 기존 대출 잔액(본인+배우자)
  - 저층 보정: 두산은 실제로 3층(저층)을 보유하고 있어, 중고층 실거래가를 그대로
    입력하면 고평가 오류가 생깁니다. "저층가 기준으로 입력함" 체크(기본값) 시
    입력가를 그대로 쓰고, 체크 해제(중고층 실거래가 등을 참고해 그대로 입력한
    경우) 시에만 -10%를 적용해 저층 등가로 환산합니다. 철산13/12단지 호가와
    부천보람 매도가의 저층 체크박스는 참고용 배지일 뿐 계산에 영향을 주지 않습니다.
- **가용 현금** = (본인 유동자산 + 배우자 유동자산) - 예비 투자금(기본 3억)
- **총 가용 자본** = 순자산 + 가용 현금
- **대출 한도**: Target 호가 > 15억 → 4억, 그 외 → 6억
- **갭 계산**: 총 필요 자금(호가 + 3.5% 제반비용) - (총 가용 자본 + 대출 한도)
- **달성률(%)** = (총 가용 자본 + 대출 한도) / 총 필요 자금 × 100

## 데이터 저장

모든 월별 입력값과 실거래가 이력은 `data/tracker.db` (SQLite)에 저장됩니다.
해당 파일은 `.gitignore`에 포함되어 저장소에 커밋되지 않습니다.
